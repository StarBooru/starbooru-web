# Roadmap

_Status as of 2026-11-23: the shell runs, with placeholder pages. Scope comes from starbooru-server's `docs/checklist.md`; the target is everything the reference web app did._

## 1. Foundation

- [x] Crate, lints, Trunk build, CI
- [x] Tokens and themes from one seed hue; the shell (brand, search, navigation)
- [ ] Sign-in with a password and with an identity provider
- [ ] Gallery: grid, infinite scroll, sorts
- [ ] Viewer: image, GIF and video, zoom, previous and next

## 2. Daily use

- [ ] Search with tag autocomplete, typo correction and the cheat sheet (`/help`)
- [ ] Tag editor, the Tags page and each tag's page
- [ ] Upload: drag and drop, folders, paste, links, chunks with progress
- [ ] Explore, saved searches, votes, related posts
- [ ] Recycle bin, mass edit

## 3. The rest of the reference

- [ ] Other boorus and library imports
- [ ] People in a post (figures)
- [ ] Image and video editor
- [ ] Duplicate finder
- [ ] Share links and the public share page (`/s/:token`)
- [ ] Settings: theme, accent, language, sessions, password, API keys
- [ ] Administration: overview, accounts, server, AI, backups
- [ ] Privacy and terms pages

## 4. Polish

- [ ] Smooth on a Raspberry Pi 4 in Chromium, the reference's target
- [ ] Effects (automatic, full, reduced) and battery saver
- [ ] English and Italian, complete
